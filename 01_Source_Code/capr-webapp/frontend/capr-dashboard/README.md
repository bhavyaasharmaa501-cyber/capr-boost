# CAPR-Net Dashboard (Angular 18)

```bash
npm install
npm start          # http://localhost:4200, talks to the API at http://localhost:5080
npx ng build       # production build (served by nginx in Docker)
```

Pages: Login, Forgot password, Dashboard, Uploads, Upload detail with SHAP explanation, Alerts,
Models, Research comparison, Users (admin), Change password dialog.
