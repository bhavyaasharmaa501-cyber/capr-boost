# Datasets

The dataset files are larger than GitHub's web upload limit, so they are not stored here.
Download them and place them at the paths below before running the experiments.

| Dataset | Path | Source |
|---------|------|--------|
| CIC-Darknet2020 | `data/Darknet2020/Darknet.CSV` | https://www.unb.ca/cic/datasets/darknet2020.html |
| CSE-CIC-IDS2018 (subset) | `data/CSE-CIC-IDS2018/ids2018_subset.csv.gz` | https://www.unb.ca/cic/datasets/ids-2018.html (subset built with `tools/build_ids2018_subset.py`) |

The trained models in `artifacts/` and the web demo work without these files.
