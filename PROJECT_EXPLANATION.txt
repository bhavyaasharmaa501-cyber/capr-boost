4. CAPR-BOOST KAISE KAAM KARTA HAI (4 STAGES)
---------------------------------------------------------------------
Preprocessing: IP/port/timestamp jaise ID columns hatao, duplicate aur
invalid rows hatao, har feature par sign(x)*log(1+|x|), phir z-score,
phir [-10, 10] me clip.

S1 - Noise-aware label refinement (galat labels pakadna)
  - Labelled data par 5-fold cross-validation se har flow ki "out-of-fold"
    probability nikalte hain (matlab us flow ko training me dekhe bina).
  - Loss = -log(probability of given label). Galat label wale flow ka loss
    zyada hota hai.
  - Har class ke liye alag 2-component Gaussian Mixture Model (GMM) fit
    karte hain loss par. Low-loss component = clean.
  - Agar flow bahut suspicious hai (clean prob < 0.2) aur model dusri class
    par confident hai (|p-0.5| > 0.3) to label FLIP karte hain (weight 0.8).
  - Baaki flows ko unke clean prob ke hisaab se weight milta hai (min 0.05).
  - Kyu per class? Anomaly class (minority) ka loss naturally zyada hota
    hai; ek hi GMM sab anomalies ko noise samajh leta.

S2 - Confidence-aware pseudo-labelling (unlabelled data use karna)
  - 3 models unlabelled flows ko predict karte hain.
  - Flow tabhi accept hota hai jab TEENO models same class bolen aur average
    confidence >= 0.97 ho.
  - Har class ke liye limit: 2 x (labelled count) x (class share). Isse
    normal class poore data ko flood nahi kar paati.
  - Accepted flows ko unke confidence ke weight ke saath training me jodte
    hain aur model dobara train karte hain.

S3 - Variant selection (kab kya use karna hai, khud decide)
  - 4 options: plain, refine, pl (sirf pseudo-label), refine+pl.
  - Labelled data par 3-fold CV se sabki accuracy dekhte hain, aur sabse
    simple option choose karte hain jo best ke 0.1% ke andar ho.
  - Test data kabhi use nahi hota.
  - Proof (viva me pooch sakte hain): agar noise rate eta < 0.5 symmetric
    hai, to noisy labels par accuracy = eta + (1 - 2*eta) * clean accuracy.
    (1 - 2*eta) positive hai, isliye jo model clean data par better hai wahi
    noisy folds par bhi better dikhega. Isliye clean validation data ki
    zarurat nahi.

S4 - Ensemble + uncertainty + explanation
  - 3 LightGBM models (500 trees, lr 0.04, 63 leaves), alag seeds.
  - Score = 3 ka average probability, threshold 0.5.
  - Uncertainty = 3 ka standard deviation (zyada = model confused).
  - TreeSHAP = har feature ne score ko kitna upar/neeche kiya (exact).

5. RESULTS (SAB MEASURED, MEAN OVER SEEDS)
---------------------------------------------------------------------
Protocol: 30% test split fixed (seed 42), kabhi training me use nahi hota.
Baaki 70% me se 0.5/1/5/10/20/100% labelled, baaki unlabelled.
Darknet2020 label sweep: 5 seeds; IDS2018: 3 seeds;
noise aur ablation: 3 seeds.

CIC-Darknet2020 (5% labels):
  CAPR-Boost      : Acc 96.94%, F1 90.99%
  LightGBM        : Acc 96.93%, F1 90.99%
  XGBoost         : Acc 97.05%, F1 91.34%
  CAPR-Net v1     : Acc 91.33%, F1 78.63%
  FixMatch        : Acc 93.08%, F1 81.94%
  Mean Teacher    : Acc 91.53%, F1 79.17%

CSE-CIC-IDS2018 subset (5% labels):
  CAPR-Boost      : Acc 99.87%, F1 99.66%

Label noise (Darknet2020, 5% labels, F1):
  Noise   CAPR-Boost   LightGBM   CAPR-Net v1   FixMatch   Mean Teacher
  10%     87.41        80.31      75.90         72.03      76.04
  20%     78.70        67.14      73.13         65.45      70.80
  30%     68.11        51.89      64.93         59.13      61.14
  40%     41.59        36.60      53.82         48.34      48.94
  => 10-30% noise par CAPR-Boost sabse robust hai (S1 refinement ki wajah se).

Deployed models (web app me jo chal rahe hain, test split par):
  darknet2020 (variant 'pl'): Accuracy 97.15%, Precision 92.19%, Recall 91.20%, F1 91.70%, AUC 0.9922
  ids2018 (variant 'plain') : Accuracy 99.90%, Precision 99.87%, Recall 99.62%, F1 99.75%, AUC 1.0000

HONEST NEGATIVES (yeh khud bata dena, examiner impress hote hain):
  - Clean labels par CAPR-Boost ~ LightGBM (same). XGBoost 0.5% labels par thoda better hai,
    LightGBM self-training 5%/10% par thoda better.
  - Pseudo-labelling (S2) ne is dataset par accuracy nahi badhayi (ablation me dikhta hai).
  - 40% noise par CAPR-Boost (41.59%) v1 (53.82%) se peeche hai.
  - Full labels par IDS2018 F1 99.91% hai; base paper CICIDS2017 par 99.98% report karta hai.
  - Base paper ka model humne re-implement nahi kiya; datasets alag hain.

9. VIVA KE POSSIBLE QUESTIONS AUR SHORT ANSWERS
---------------------------------------------------------------------
Q: Aapki accuracy base paper se kam/zyada kyu hai?
A: Dataset alag hai (section 2). Same lab ke IDS2018 par hum same range me
   hain. Hum beat karne ka claim nahi karte.

Q: Colab me 97.15% aaya, paper me 96.94% kyu likha hai?
A: Part A ek seed (seed 0) ka result hai. Paper 5 seeds ka average deta
   hai. Part B wahi 5 seeds chalata hai aur exactly 96.94% deta hai
   (diff 0.00), kyunki code, seeds aur test split same hain.

Q: Neural network chhod ke trees kyu?
A: Flow features tabular hain; trees yahan consistently better hain
   (Grinsztajn 2022, Shwartz-Ziv 2022). Humare experiment me bhi har label
   ratio par trees > MLP/FixMatch/Mean Teacher.

Q: CAPR-Boost aur plain LightGBM me kya fark hai agar clean labels par
   dono same hain?
A: Clean labels par S3 khud extra stages band kar deta hai, isliye same
   result. Fark noisy labels par dikhta hai (S1), aur uncertainty +
   explanation extra milta hai.

Q: Test data leak to nahi hua?
A: Test split pehle hi fix hai (seed 42), variant selection sirf labelled
   training data par, noise sirf labelled training par, demo CSV sirf test
   split se, duplicates split se pehle hataye.

Q: GMM kyu?
A: Clean aur noisy flows ka loss distribution alag hota hai (do peaks);
   2-component GMM in dono ko alag karta hai (Arazo 2019, DivideMix).

Q: Uncertainty kaise?
A: 3 models alag seeds se; unke predictions ka std. Zyada std = review
   karo. Alert severity bhi isse adjust hoti hai.

Q: Forgot password secure kaise hai?
A: Code random (RandomNumberGenerator), DB me sirf hash, 15 min expiry,
   5 attempts, rate limit, generic response, audit log.

Q: 40% noise par kya hota hai?
A: Wahan S1 noisy aur hard examples me fark nahi kar pata; yeh limitation
   hai, report me likha hai.
